## 🚀 Começando

Para adicionar um novo projeto:

1. **Escolha a categoria apropriada**
2. **Crie uma pasta com nome descritivo** (ex: `meu-projeto`)
3. **Adicione um README.md** detalhado
4. **Organize o código** em subpastas claras
5. **Documente bem** com exemplos de uso

---

## 📖 Template de Estrutura

```
meu-projeto/
├── README.md           # Documentação principal
├── requirements.txt    # Dependências Python
├── src/               # Código fonte
│   ├── main.py
│   └── utils.py
├── data/              # Datasets (se aplicável)
├── notebooks/         # Jupyter notebooks
├── tests/             # Testes
└── docs/              # Documentação adicional
```
