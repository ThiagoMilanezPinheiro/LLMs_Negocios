# 📊 Análise de Dados

Bem-vindo à seção de **Análise de Dados**! Aqui estão projetos de análise exploratória, visualizações e business intelligence.

## 📋 Subpastas

### [Análise de Terremotos e Sismos](../../../docs/projetos/analise-simicos/index.html)
Pipeline para coletar dados recentes da API USGS, normalizar eventos, inferir regiões/países e gerar gráficos e relatórios com drill-down temporal e geográfico.

### [Análise de Vendas Q3](./analise-vendas-q3/) *(Exemplo)*
Análise exploratória de dados de vendas do terceiro trimestre.

### [Dashboard de KPIs](./dashboard-kpis/) *(Planejado)*
Dashboard interativo de indicadores-chave de desempenho.

### [Análise de Churn](./analise-churn/) *(Planejado)*
Análise de taxa de cancelamento de clientes.

### [Segmentação de Clientes](./segmentacao-clientes/) *(Planejado)*
Segmentação de base de clientes para marketing direcionado.

---

## 🎯 Tipos de Projetos Nesta Categoria

- **EDA (Exploratory Data Analysis)** - Exploração inicial de dados
- **Business Intelligence** - Dashboards e relatórios
- **Análise Estatística** - Testes e modelagem estatística
- **Visualizações Avançadas** - Gráficos interativos e storytelling com dados
- **Relatórios Automatizados** - Relatórios gerados automaticamente

---

## 🚀 Ferramentas Recomendadas

- **Pandas** - Manipulação de dados
- **Matplotlib/Seaborn** - Visualizações estáticas
- **Plotly** - Visualizações interativas
- **Power BI/Tableau** - Business Intelligence
- **Streamlit** - Dashboards em Python

---

## 💡 Ideias para Projetos

- Análise de desempenho por região
- Análise de comportamento do consumidor
- Previsão de demanda
- Análise de correlação entre variáveis
- Identificação de anomalias em vendas
- Análise de satisfação do cliente
- Comparação de períodos (YoY, MoM)
