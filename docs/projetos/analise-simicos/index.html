Análise de Terremotos e Sismos

Pipeline de análise criado para coletar dados recentes da API do USGS, normalizar eventos, inferir regiões e países, e gerar gráficos e relatórios com foco em drill-down temporal e geográfico.

📍 Visão Geral do Projeto

Este projeto reúne dados reais de terremotos e organiza a informação em visualizações por região, país, ano, mês e dia, permitindo uma navegação mais precisa dos eventos sísmicos mais recentes.
